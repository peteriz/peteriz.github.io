Mancia

Edit text with AI in any macOS app, without leaving the app you write in.

Mancia uses GitHub Copilot CLI to edit selected text in place. Built-in actions cover common edits, while Custom accepts any instruction. The menu bar workflow keeps the source app in focus, and clipboard restoration preserves what you copied before the edit. Mancia collects no telemetry.
